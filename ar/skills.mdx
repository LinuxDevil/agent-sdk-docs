الـ skill هي مجموعة تعليمات لها اسم (مستند markdown) يحمّلها الـ model **فقط لما يحتاجها**. هذي هي فكرة progressive disclosure: بدل ما تلصق كل playbook في الـ system prompt، تسرد الـ skills بالاسم مع وصف من سطر واحد، والـ model يجيب النص الكامل عند الطلب.

كيف تمشي الأمور لما يكون عند الـ agent skills:

1. ينضاف للـ system prompt قسم صغير بعنوان **Available skills**: سطر لكل skill (`- name: description`)، وجملة واحدة تقول للـ model ينادي `load_skill` قبل أي مهمة تغطيها skill.
2. تتسجّل تلقائيًا tool باسم `load_skill` (مدخلها `{ name }`). ترجع المحتوى الكامل للـ skill كنتيجة للـ tool.
3. نصوص الـ skills **ليست** في الـ prompt قبل ما تنحمّل. agent عنده عشرين skill طويلة يدفع تقريبًا سطر واحد لكل skill في كل طلب، وتكلفة النص الكامل بس في الـ runs التي تستخدمه.

لو الاسم غير معروف، ترجع الـ tool خطأ يسرد أسماء الـ skills الصالحة، فيقدر الـ model يصحح نفسه.

## Skills في الكود

```ts
import { createAgent, defineSkill } from '@lousho/build-ai-agent';

const agent = createAgent({
  prompt: 'You are a release engineer.',
  provider,
  skills: [
    defineSkill({
      name: 'changelog',
      description: 'How to write a changelog entry',
      content: '# Changelog entries\n\nUse the imperative mood and link the PR.',
    }),
  ],
});
```

`defineSkill({ name, description, content })` تتحقق من مدخلاتها. `name` لازم يطابق `^[a-z0-9][a-z0-9-_]{0,63}$`، و`description` و`content` لازم ما يكونوا فاضيين. الأخطاء تقول لك وين المشكلة وكيف تصلحها.

`AgentExecutor.execute()` ياخذ نفس خيار `skills`؛ شوف [الـ executor API](/ar/executor-api).

لو عندك tool مسجّلة باسم `load_skill` من قبل، تمرير `skills` يرمي خطأ: غيّر اسم الـ tool أو احذف الخيار.

## Skills من القرص

`loadSkills(dir)` يقرأ ملفات الـ skills، فيقدر غير المطورين يعدلوها بدون ما يلمسوا الكود. فيه تنسيقين مدعومين وتقدر تخلط بينهم في مجلد واحد:

```
skills/
  changelog/SKILL.md      # <name>/SKILL.md  (Anthropic / open-harness convention)
  code-review.md          # <name>.md        (eve convention)
```

كل ملف يبدأ بـ YAML frontmatter، والباقي هو محتوى الـ skill:

```markdown
---
description: How to write a changelog entry
---

# Changelog entries

Use the imperative mood and link the PR.
```

- `description` مطلوب.
- `name` اختياري، وقيمته الافتراضية اسم المجلد (في تنسيق `SKILL.md`) أو اسم الملف بدون `.md`.
- المجلدات اللي ما فيها `SKILL.md` نتجاهلها.
- الـ skills ترجع مرتبة بالاسم، فالنتيجة deterministic.
- الأخطاء تسمي الملف والمشكلة: `description` ناقص، YAML غير صالح، اسم غير صالح، مجلد ما يتقرى، أو skill-ين بنفس الاسم (والمسارين الاثنين مذكورين).

```ts
import { createAgent, loadSkills } from '@lousho/build-ai-agent';

const agent = createAgent({
  prompt: 'You are a release engineer.',
  provider,
  skills: [...(await loadSkills('./skills'))],
});
```
