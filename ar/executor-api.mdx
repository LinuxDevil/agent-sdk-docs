الدالة `createAgent()` هي نقطة الدخول الموصى بها (انظر [البدء السريع](/ar/quickstart)). هذه الصفحة موجّهة للشيفرة التي تحتاج إلى الخيارات الأدنى مستوى التي لا تقبلها `createAgent()`. وللانتقال بشيفرة المنفّذ الحالية إلى `createAgent()`، انظر [الانتقال إلى createAgent()](/ar/migrating-to-create-agent).

## `AgentBuilder` و`AgentExecutor`

`createAgent()` غلاف رقيق فوق `AgentBuilder` ودالة `AgentExecutor.execute()` الساكنة.
لا تستخدمهما مباشرة إلا فيما لا تقبله `createAgent()`:
`temperature` و`maxTokens`، و`TraceExporter` للتتبّع
(`exporter` و`captureContent`). أما `createAgent()` فتقبل أصلًا `maxSteps`
و`limits` و`onEvent` والموافقات و`store` (نقاط الحفظ) و`hooks` و`compaction`. `AgentExecutor` واجهة ساكنة (static)، فلا
وجود لـ `new AgentExecutor()`.

```ts
import {
  AgentBuilder,
  AgentExecutor,
  createMockProvider,
} from '@lousho/build-ai-agent';

const agent = AgentBuilder.create()
  .setName('Customer Support Agent')
  .setPrompt('You are a helpful customer support assistant.')
  .build();

const events: string[] = [];
const result = await AgentExecutor.execute({
  agent,
  input: 'My order arrived damaged.',
  provider: createMockProvider({ responses: ["I'm sorry to hear that - what's your order number?"] }),
  maxSteps: 5,
  onAgentEvent: (event) => events.push(event.type),
});

console.log(result.text);
console.log(result.usage.totalTokens, result.finishReason, result.steps);
console.log(events); // includes 'run.start' and 'run.done'
```

## مشاركة الأدوات عبر `ToolRegistry`

*متقدم: `ToolRegistry`.* لمشاركة الأدوات بين عدة وكلاء أو لتسجيل
`ToolDescriptor` الخام، استخدم `registry.register(tool)` للأداة المعرَّفة أو
`registry.register(name, descriptor)` للواصف. مرّر السجل بوصفه
`toolRegistry` إلى `AgentExecutor.execute()`. انظر
[الأدوات](/ar/tools#متقدم-toolregistry) للاطلاع على مثال كامل.

## خيارات `AgentExecutor.execute()`

`AgentExecutor` ساكن: استدعِ `AgentExecutor.execute(options)`. الخيارات المطلوبة هي
`agent` و`input` و`provider` فقط. وهذه الخيارات الأكثر استخدامًا:

| الخيار                                  | الوصف                                                           |
| --------------------------------------- | --------------------------------------------------------------- |
| `agent`                                 | قيمة من النوع `AgentConfig`، تُبنى عادةً بـ `AgentBuilder`.      |
| `input`                                 | رسالة مستخدم نصية، أو محادثة من النوع `Message[]`.               |
| `provider`                              | الـ `LLMProvider` الذي يُولَّد به الرد.                          |
| `toolRegistry`                          | `ToolRegistry` يضم الأدوات التي تشير إليها إعدادات الوكيل.       |
| `maxSteps`                              | الحد الأعلى لخطوات النموذج والأدوات.                             |
| `limits`                                | ميزانيات التشغيل من الرموز والتكلفة والوقت والخطوات؛ انظر [الميزانيات](/ar/configuration#الميزانيات). |
| `temperature`, `maxTokens`              | معاملات التوليد.                                                |
| `onAgentEvent`                          | مستمع لأحداث `AgentEvent` الخاصة بالتشغيل (`run.start` و`tool.start` و`run.done` وغيرها)؛ انظر [البث](/ar/streaming#الاستماع-دون-المرور-على-الأحداث). |
| `streamModelCalls`                      | مع وجود مستمع، يبث كل استدعاء للنموذج فيصل النص في عدة أحداث `text.delta` (الافتراضي `true`)؛ أما `false` فيولّد الخطوات كاملة، بحدث `text.delta` واحد لكل خطوة. يتجاهله `stream()`. |
| `approvalStore`, `sessionId`            | موافقات إشراك الإنسان (انظر `resumeAfterApproval()`).            |
| `checkpointStore`                       | حفظ نقاط حفظ التنفيذ واستئنافها.                                 |
| `exporter`                              | `TraceExporter` لمقاطع التتبّع (اصطلاحات OpenTelemetry GenAI، انظر [المراقبة](/ar/observability)). |
| `captureContent`, `redactContent`       | تسجيل محتوى الرسائل والأدوات في سمات المقاطع `gen_ai.*` (اختياري) / حذف سمات المحتوى المُهمَلة. |
| `onLLMRequest`, `onLLMResponse`, `onToolCall`, `onToolResult` | خطّافات المراقبة.                |
| `toolSearch`                            | يضبط [البحث عن الأدوات](/ar/tool-search) للأدوات المعلَّمة بـ `deferLoading`، أو `false` لإرسال كل أداة في كل استدعاء. |

وتُنجَز بنتيجة من النوع `ExecutionResult`: `{ text, messages, toolCalls, usage,
finishReason, steps, approvalId? }`.
