`loushoAgent()` لـSvelte هي نفس [React hook](/ar/react) لكن بصيغة store: نفس
المصادر، نفس الحالة، نفس الأوامر، فوق نفس [typed event stream](/ar/streaming).
صفحة [React](/ar/react) تشرح معنى كل حقل، ونوعَي المصدر، وكيف تعمل approvals
(الموافقات)، وجانب السيرفر. هذه الصفحة تغطي الفروقات فقط.

موجودة في الـsubpath `@lousho/build-ai-agent/svelte`. الـstore ينفّذ عقد الـstores
في Svelte (`subscribe(run) => unsubscribe`) يدويًا، فيعمل مع `$agent` في Svelte 4
و5، ولا يحتاج أي import لـ`svelte`: لا توجد peer dependency تثبّتها.

```ts
import { loushoAgent } from '@lousho/build-ai-agent/svelte';

// In a component's <script lang="ts">, or a module that several components share:
export const agent = loushoAgent({ url: '/api/agent' }, { approvalsUrl: '/api/approvals' });

export async function submit(text: string): Promise<void> {
  if (text.trim()) await agent.send(text);
}
```

وفي المكوّن (قالب Svelte، فلا يمر على الـtype-check مع بقية المقاطع هنا):

```html
{#each $agent.messages as message (message.id)}
  <article>
    <header>{message.role}</header>
    <p>{message.text}</p>
    {#each message.toolCalls ?? [] as call (call.id)}
      <code>{call.name}: {call.status}</code>
    {/each}
  </article>
{/each}
{#if $agent.pendingApproval}
  <p>
    Run {$agent.pendingApproval.toolName}?
    <button on:click={() => agent.approve()}>Approve</button>
    <button on:click={() => agent.reject('Not now')}>Reject</button>
  </p>
{/if}
{#if $agent.status === 'streaming'}<button on:click={agent.stop}>Stop</button>{/if}
```

## ما يختلف عن React

- **الحالة هي قيمة الـstore.** `$agent` هو كائن الحالة الذي يرجعه React hook:
  `messages` و`status` و`pendingApproval` و`error` و`usage` و`todos` و`lastEvent`.
  الأوامر (`send` و`stop` و`approve` و`reject` و`answer`) موجودة على الـstore
  نفسه وبنفس تواقيع React hook، ولا تحتاج إلى subscriber.
- **`reset()`** يلغي الـrun الجاري، وينسى الـsession الحالية داخل العملية
  (`{ agent, sessionId }` يبدأ محادثة جديدة)، ويمسح الحالة.
- **المصدر والخيارات قيم عادية** تُقرأ عند بدء turn. إذا أردت agent آخر أو `url`
  آخر، أنشئ store جديد.
- **التنظيف هو إلغاء الاشتراك.** `stop()` يلغي الطلب الجاري، ونفس الشيء يحدث
  عند رحيل آخر subscriber (عندما يتدمّر المكوّن الذي يستخدم `$agent`). لا توجد
  `destroy()`: هكذا توقف Svelte stores عملها. الـstore الذي لا يشترك فيه أحد
  يكمل turn بدأته بـ`send()`؛ إذا تخليت عنه، استدعِ `stop()` بنفسك.

الـreducer وparser الخاص بالـstream مُصدَّران من هذا الـsubpath أيضًا
(`reduceAgentEvents` و`initialAgentUIState` و`parseEventStream`)، وهما نفسهما
الموجودان في `@lousho/build-ai-agent/react`.

## Todos

`loushoTodos(agent)` هو readable store مشتق من الـstore الذي يرجعه
`loushoAgent()`: `$plan` هو عرض الـtodos ويحتوي على `todos` و`counts` و`current`
(عنصر `in_progress`، وإلا فأول عنصر `pending`) و`progress`
(`completed / total`). يعرض خطة الـagent الذي يستخدم
[todo tools](/ar/tools#todo-tools) بشكل live، من نفس الـstream الذي
تعتمد عليه المحادثة، ولا يرسل إشعارات إلا عندما تتغير القائمة (انظر
[React](/ar/react#todos)).

```ts
import { loushoAgent, loushoTodos } from '@lousho/build-ai-agent/svelte';

export const agent = loushoAgent({ url: '/api/agent' });
export const plan = loushoTodos(agent);
```

```html
<p>{$plan.counts.completed} of {$plan.counts.total} done ({Math.round($plan.progress * 100)}%)</p>
{#if $plan.current}<p>Now: {$plan.current.content}</p>{/if}
<ul>
  {#each $plan.todos as todo (todo.id)}<li>{todo.status}: {todo.content}</li>{/each}
</ul>
```
