## ابدأ مشروعًا جديدًا

أسرع طريق للبدء أمر واحد ينشئ مشروعًا قابلًا للتشغيل (وكيل، وأداة نموذجية، واختبار يعمل دون اتصال، وملف `.env.example` لمزوّدك)، ويثبّت اعتمادياته وينفّذ `git init`:

```bash
npx lousho init my-agent
cd my-agent
cp .env.example .env     # put your API key in .env
npm run dev              # chat with your agent in the terminal
npm test                 # offline tests: no API key needed
```

الأمر `npm create lousho-agent my-agent` مكافئ له، وكذلك `npx @lousho/build-ai-agent init my-agent` حين لا تكون الحزمة مثبّتة بعد (فالأمر `npx lousho` المجرّد لا يجد الأمر `lousho` إلا بعد وجود الحزمة في `node_modules` لديك). ومن دون وسائط يسأل `init` عن المجلد والمزوّد والقالب؛ ويسرد `lousho init --help` كل الرايات.

تفضّل إضافة الحزمة إلى مشروع قائم؟ ثبّتها يدويًا (راجع [التثبيت](/ar/installation)):

```bash
npm install @lousho/build-ai-agent ai@^7.0.0 zod
npm install @ai-sdk/openai@^4.0.0 @ai-sdk/anthropic@^4.0.0
```

هذا هو الإصدار الرئيسي الحالي من `ai`؛ ومع Ollama استخدم `ai@^7.0.0` مع `ollama-ai-provider-v2@^4.0.0` وzod 4 (راجع [أزواج الحزم المتوافقة](/ar/installation#حزم-المزوّدين)).

## 1. «مرحبًا بالعالم»

`createAgent()` هي نقطة الدخول التي لا تحتاج إلى إعداد: تعطيها سلسلة `provider/model` وتعليمات، فتعطيك وكيلًا بواجهة `{ send }`. يُقرأ مفتاح API من متغير البيئة المتعارف عليه للمزوّد (`OPENAI_API_KEY` هنا؛ و`ANTHROPIC_API_KEY` أو `OPENROUTER_API_KEY` أو `OLLAMA_BASE_URL` للمزوّدين الآخرين). بادئة النموذج `vendor/` هي التي تختار المزوّد؛ ومع OpenRouter استخدم `openrouter/<vendor>/<model>` (مثل `openrouter/openai/gpt-4o-mini`).

```ts
import { createAgent } from '@lousho/build-ai-agent';

const agent = createAgent({ model: 'openai/gpt-4o-mini', instructions: 'You are a helpful assistant.' });
const { text } = await agent.send('Hello!');
console.log(text);
```

احذف `model` لتترك القرار للبيئة: `LOUSHO_MODEL` (سلسلة `provider/model`) إن كان مضبوطًا، وإلا أول الموجود من `OPENAI_API_KEY` و`ANTHROPIC_API_KEY` و`OPENROUTER_API_KEY` و`OLLAMA_BASE_URL`. وإذا كان مفتاح ناقصًا أو كُتبت البادئة خطأً، يخبرك الخطأ بالضبط بما يجب ضبطه أو تصحيحه. `instructions` اختياري؛ ويُقبل `prompt` اسمًا بديلًا له.

## 2. أضف أداة

عرّف الأداة بـ `defineTool()`: تُستمد أنواع وسائط `execute` و`needsApproval` من مخطط zod في `input`، ويدخل الناتج مباشرة في `createAgent({ tools: [...] })`. يحاكي المزوّد الوهمي استدعاء أداة كلما ذكرت رسالة المستخدم اسم أداة، ولذلك يختبر هذا المقتطف دورة استدعاء أداة حقيقية كاملة، ذهابًا وإيابًا، دون LLM.

```ts
import { createAgent, createMockProvider, defineTool } from '@lousho/build-ai-agent';
import { z } from 'zod';

const currentDate = defineTool({
  name: 'current_date',
  description: 'Get the current date',
  input: z.object({}),
  async execute() {
    return { date: new Date().toISOString().slice(0, 10) };
  },
});

const agent = createAgent({
  prompt: 'You are a scheduling assistant. Use tools when helpful.',
  provider: createMockProvider({ responses: ['Let me check.', 'Here is the date you asked for.'] }),
  tools: [currentDate],
});

const result = await agent.send('Please call current_date for me');
console.log(result.toolCalls.map((call) => call.function.name)); // [ 'current_date' ]
console.log(result.text);
```

يجب أن تتكون الأسماء من 1 إلى 64 محرفًا من الحروف والأرقام و`_` أو `-`. راجع [الأدوات](/ar/tools) للاطلاع على التحقق والأخطاء والأدوات المضمَّنة.

## 3. بُثّ الإجابة

يشغّل `agent.stream()` الوكيل مثل `send()` ويُعيد `AgentRun`: مرّ عليه بحلقة للحصول على أحداث مُنمَّطة (نص النموذج فور وصوله، واستدعاءات الأدوات، وحدود الخطوات)، وانتظر `run.result` للحصول على النتيجة نفسها التي تُعيدها `send()`.

```ts
import { createAgent, createMockProvider } from '@lousho/build-ai-agent';

const agent = createAgent({
  prompt: 'You are a helpful assistant.',
  provider: createMockProvider({ responses: ['Streaming works word by word.'] }),
});

const run = agent.stream('Tell me something.');
for await (const event of run) {
  if (event.type === 'text.delta') process.stdout.write(event.text);
}
process.stdout.write('\n');

const result = await run.result;
console.log(result.finishReason); // "stop"
```

راجع [البث](/ar/streaming) للاطلاع على قائمة الأحداث الكاملة والإلغاء وإرسال الأحداث إلى المتصفح.

## 4. تذكّر المحادثة

تبدأ `agent.send()` من سجل فارغ في كل استدعاء. أما `agent.session()` فتحتفظ بالنص وتمرّره إلى النموذج في كل `send()`.

```ts
import { createAgent, createMockProvider } from '@lousho/build-ai-agent';

const agent = createAgent({
  prompt: 'You are a helpful assistant.',
  provider: createMockProvider({ responses: ['Nice to meet you, Ali.', 'Your name is Ali.'] }),
});

const session = agent.session();
await session.send('My name is Ali.');
const { text } = await session.send('What is my name?');

console.log(text);
console.log(session.messages.length); // 4: two user messages and two replies
```

مرّر مخزنًا للإبقاء على الجلسات عبر إعادات التشغيل؛ راجع [الجلسات](/ar/sessions).

## 5. اسأل قبل إجراء فيه خطورة

اجعل الأداة `needsApproval` فيتوقف التشغيل قبل استدعائها. تنتهي `send()` بـ `finishReason: 'awaiting-approval'` وبـ `approvalId`؛ ثم يوافق كودك (أو إنسان) على الاستدعاء أو يرفضه ويتابع التشغيل. هنا يكتب `mockModel` من `@lousho/build-ai-agent/testing` دورات النموذج بدقة، فيكون استدعاء الأداة مؤكدًا.

```ts
import { createAgent, defineTool } from '@lousho/build-ai-agent';
import { mockModel } from '@lousho/build-ai-agent/testing';
import { z } from 'zod';

const sendEmail = defineTool({
  name: 'send_email',
  description: 'Send an email',
  input: z.object({ to: z.string() }),
  needsApproval: true,
  execute: async ({ to }) => `sent to ${to}`,
});

const agent = createAgent({
  instructions: 'You send emails.',
  provider: mockModel([
    { toolCalls: [{ name: 'send_email', args: { to: 'sam@example.com' } }] },
    { text: 'Sent.' },
  ]),
  tools: [sendEmail],
});

const paused = await agent.send('Email the report to sam@example.com');
console.log(paused.finishReason); // "awaiting-approval"

const result = await agent.approvals.resolve({ id: paused.approvalId!, approved: true });
console.log(result.text); // "Sent."
```

مرّر `approved: false` (مع `note`) لرفض الاستدعاء بدلًا من ذلك. راجع [الموافقات](/ar/approvals) للاطلاع على الدوال الشرطية والمخازن والبتّ من عملية أخرى.

## 6. اختبره دون اتصال

الوكيل من الخطوة السابقة قابل للاختبار أصلًا: يسجّل `mockModel` كل طلب أرسله الوكيل، فتستطيع التحقق مما أُرسل إلى النموذج وكذلك من النتيجة. لا شبكة ولا مفتاح.

```ts
import { createAgent, defineTool } from '@lousho/build-ai-agent';
import { mockModel } from '@lousho/build-ai-agent/testing';
import { z } from 'zod';

let sent: string | undefined;
const sendEmail = defineTool({
  name: 'send_email',
  description: 'Send an email',
  input: z.object({ to: z.string() }),
  needsApproval: true,
  execute: async ({ to }) => {
    sent = to;
    return `sent to ${to}`;
  },
});

const model = mockModel([
  { toolCalls: [{ name: 'send_email', args: { to: 'sam@example.com' } }] },
  { text: 'Sent.' },
]);
const agent = createAgent({ instructions: 'You send emails.', provider: model, tools: [sendEmail] });

const paused = await agent.send('Email the report to sam@example.com');
const result = await agent.approvals.resolve({ id: paused.approvalId!, approved: true });

function check(ok: boolean, message: string): void {
  if (!ok) throw new Error(`Assertion failed: ${message}`);
}
check(result.text === 'Sent.', 'final answer');
check(sent === 'sam@example.com', 'the tool ran with the approved arguments');
check(model.calls.length === 2, 'the model was called twice');
model.assertExhausted(); // throws if a scripted turn was never used
console.log('ok');
```

في مشروع حقيقي، ضع التحققات نفسها في اختبار vitest أو Jest. راجع [الاختبار](/ar/testing) لتسلسلات استدعاء الأدوات ودورات الخطأ و`recordReplay`.

## 7. مزوّد مخصّص

`model: 'provider/model'` هو الاختصار؛ مرّر `provider` بدلًا منه عندما يكون لديك `LLMProvider` خاص بك أو تريد المزوّد الوهمي للاختبارات. و`resolveProvider('<provider>/<model>')` هي الدالة التي يستخدمها `model` داخليًا. يستخدم هذا المقتطف OpenAI إذا كان `OPENAI_API_KEY` مضبوطًا ويرجع إلى المزوّد الوهمي في غير ذلك، وهو النمط نفسه الذي تتبعه [الأمثلة](https://github.com/LinuxDevil/agent-sdk/blob/main/examples/README.md) القابلة للتشغيل.

```ts
import { createAgent, createMockProvider, resolveProvider } from '@lousho/build-ai-agent';

const provider = process.env.OPENAI_API_KEY
  ? resolveProvider('openai/gpt-4o-mini')
  : createMockProvider({ responses: ['Paris.'] });

const agent = createAgent({
  name: 'geography-bot',
  prompt: 'Answer geography questions in one word.',
  provider,
});

const result = await agent.send('What is the capital of France?');
console.log(result.text);
```

## 8. الوكلاء التصريحيون: ملفات المواصفات

يمكن أيضًا وصف الوكيل على هيئة بيانات مجرّدة، أي `AgentSpec`، ثم تحويله إلى وكيل حيّ بـ `specToAgent()`. ويمكن كتابة البنية نفسها في ملف YAML أو JSON وتحميلها بـ `loadSpec()`.

```ts
import { specToAgent, agentSpecSchema } from '@lousho/build-ai-agent';

const spec = agentSpecSchema.parse({
  name: 'support-bot',
  prompt: 'You are a friendly support agent.',
  provider: { type: 'mock', model: 'mock-1' },
  tools: ['current-date'],
});

const agent = specToAgent(spec);
const result = await agent.send('Hello!');
console.log(result.text);
```

وعند حفظه باسم `agent.yaml`:

```yaml
name: support-bot
prompt: You are a friendly support agent.
provider:
  type: mock
  model: mock-1
tools:
  - current-date
```

يعمل ملف المواصفات نفسه في خادم التطوير المحلي (واجهة المحادثة على `/`، و`POST /chat`، وإعادة تحميل فورية عند الحفظ) ويُبنى خادمًا قابلًا للنشر:

```bash
npx lousho dev agent.yaml
npx lousho build --target=node-server --agent=agent.yaml
```

## متقدم: واجهة المنفّذ

`createAgent()` هي نقطة الدخول الموصى بها. وهي تقوم فوق `AgentBuilder` والدالة الساكنة `AgentExecutor.execute()`، اللتين تقبلان بعض الخيارات الأدنى مستوى التي لا تقبلها `createAgent()`، مثل `temperature` و`maxTokens`. راجع [واجهة المنفّذ](/ar/executor-api).
