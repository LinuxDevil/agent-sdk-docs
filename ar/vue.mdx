`useLoushoAgent()` في Vue 3 هو [الـ hook الخاص بـReact](/ar/react) نفسه، لكن على شكل
composable: المصادر نفسها، والحالة نفسها، والأوامر نفسها، فوق الـ
[typed event stream](/ar/streaming) نفسه. صفحة [React](/ar/react) تشرح معنى كل
حقل، ونوعي الـ source، وكيف تعمل الـ approvals (الموافقات)، وجهة السيرفر.
هذه الصفحة تغطي الفروقات فقط.

الـ composable موجود في الـ subpath `lousho/vue`.
و`vue` (3.x) هي peer dependency اختيارية: ثبّتها في التطبيق الذي يستخدم
الـ composable.

```ts
import { useLoushoAgent } from 'lousho/vue';

// In <script setup>:
const { messages, status, pendingApproval, send, stop, approve, reject, reset } = useLoushoAgent(
  { url: '/api/agent' },
  { approvalsUrl: '/api/approvals' }
);

export async function submit(text: string): Promise<void> {
  if (text.trim() && status.value !== 'streaming') await send(text);
}

export { messages, status, pendingApproval, stop, approve, reject, reset };
```

وفي الـ template:

```html
<article v-for="message in messages" :key="message.id">
  <header>{{ message.role }}</header>
  <p>{{ message.text }}</p>
  <code v-for="call in message.toolCalls" :key="call.id">{{ call.name }}: {{ call.status }}</code>
</article>
<p v-if="pendingApproval">
  Run {{ pendingApproval.toolName }}?
  <button @click="approve()">Approve</button>
  <button @click="reject('Not now')">Reject</button>
</p>
<button v-if="status === 'streaming'" @click="stop">Stop</button>
```

## ما يختلف عن React

- **الحالة كلها refs.** `messages` و`status` و`pendingApproval` و`error`
  و`usage` و`finishReason` و`todos` و`partialObject` و`lastEvent` كلها `ComputedRef` للقراءة فقط: تستخدم
  `.value` في الـ script، ولا تحتاجها في الـ template. أما الأوامر
  (`send` و`stop` و`approve` و`reject` و`answer`) فهي دوال عادية بتواقيع
  الـ hook في React نفسها.
- **`reset()`** توقف الـ run الجاري، وتنسى الـ session المخزنة داخل
  العملية (`{ agent, sessionId }` يبدأ محادثة جديدة، ومصدر `{ url }` البعيد يأخذ معرّف محادثة جديدًا مولَّدًا)، وتصفّر الحالة.
- **يمكن أن تكون الـ source والـ options refs.** مرّر object عاديًا أو `ref`؛
  تُقرأ القيمة عندما يبدأ turn جديد، فإذا غيّرت `url` أو `agent` فإن التغيير
  ينطبق على الـ turn التالي.
- **التنظيف يتم بإيقاف الـ scope.** `stop()` تلغي الطلب الجاري، وإيقاف
  الـ scope المالك يفعل الشيء نفسه: unmount لمكوّن، أو
  `effectScope().stop()` في الاختبارات والسكربتات العادية. إذا استدعيت الـ
  composable خارج أي scope، فليس لديه ما يتخلص منه، فاستدعِ `stop()`
  بنفسك.

يمكنك استيراد الـ reducer والـ stream parser من الـ subpath نفسه
(`reduceAgentEvents` و`initialAgentUIState` و`parseEventStream`)، وهي نفسها
الموجودة في `lousho/react`.

## Todos

`useTodos(agent)` تأخذ نتيجة الـ composable وتُرجع ref واحدًا للقراءة فقط
لكل حقل في عرض الـ todos: `todos` و`counts` و`current` (عنصر الـ
`in_progress`، وإن لم يوجد، فأول عنصر `pending`) و`progress`
(`completed / total`). تعرض خطة الـ agent الذي يستخدم
[todo tools](/ar/tools#todo-tools) live، من الـ stream نفسه الذي يغذي
المحادثة (راجع [React](/ar/react#todos)).

```ts
import { useLoushoAgent, useTodos } from 'lousho/vue';

// In <script setup>:
const agent = useLoushoAgent({ url: '/api/agent' });
const { todos, counts, current, progress } = useTodos(agent);

export { agent, todos, counts, current, progress };
```

```html
<p>{{ counts.completed }} of {{ counts.total }} done ({{ Math.round(progress * 100) }}%)</p>
<p v-if="current">Now: {{ current.content }}</p>
<ul>
  <li v-for="todo in todos" :key="todo.id">{{ todo.status }}: {{ todo.content }}</li>
</ul>
```
