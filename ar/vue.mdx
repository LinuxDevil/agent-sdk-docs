`useLoushoAgent()` في Vue 3 هو نفس الـ hook الخاص بـReact، بس على شكل
composable: نفس المصادر، نفس الحالة، نفس الأوامر، فوق نفس الـ
[typed event stream](/ar/streaming). صفحة [React](/ar/react) تشرح معنى كل
حقل، ونوعي الـ source، وكيف تشتغل الـ approvals (الموافقات)، وجهة السيرفر.
هذه الصفحة تغطي بس الفروقات.

الـ composable موجود في الـ subpath `@lousho/build-ai-agent/vue`.
و`vue` (3.x) هي peer dependency اختيارية: ثبّتها في التطبيق اللي يستخدم
الـ composable.

```ts
import { useLoushoAgent } from '@lousho/build-ai-agent/vue';

// In <script setup>:
const { messages, status, pendingApproval, send, stop, approve, reject, reset } = useLoushoAgent(
  { url: '/api/agent' },
  { approvalsUrl: '/api/approvals' }
);

export async function submit(text: string): Promise<void> {
  if (text.trim() && status.value !== 'streaming') await send(text);
}

export { messages, status, pendingApproval, stop, approve, reject, reset };
```

وفي الـ template:

```html
<article v-for="message in messages" :key="message.id">
  <header>{{ message.role }}</header>
  <p>{{ message.text }}</p>
  <code v-for="call in message.toolCalls" :key="call.id">{{ call.name }}: {{ call.status }}</code>
</article>
<p v-if="pendingApproval">
  Run {{ pendingApproval.toolName }}?
  <button @click="approve()">Approve</button>
  <button @click="reject('Not now')">Reject</button>
</p>
<button v-if="status === 'streaming'" @click="stop">Stop</button>
```

## ما يختلف عن React

- **الحالة كلها refs.** `messages` و`status` و`pendingApproval` و`error`
  و`usage` و`todos` و`lastEvent` كلها `ComputedRef` للقراءة فقط: تستخدم
  `.value` في الـ script، وفي الـ template ما تحتاجها. أما الأوامر
  (`send` و`stop` و`approve` و`reject` و`answer`) فهي دوال عادية بنفس
  تواقيع الـ hook في React.
- **`reset()`** توقف الـ run الجاري، وتنسى الـ session المخزنة داخل
  العملية (`{ agent, sessionId }` يبدأ محادثة جديدة)، وتصفّر الحالة.
- **الـ source والـ options ممكن تكون refs.** مرّر object عادي أو `ref`؛
  القيمة تُقرأ لما يبدأ turn جديد، فلو غيّرت `url` أو `agent` التغيير
  ينطبق على الـ turn الجاي.
- **التنظيف يتم بإيقاف الـ scope.** `stop()` تلغي الطلب الجاري، وإيقاف
  الـ scope المالك يسوي نفس الشي: unmount لمكوّن، أو
  `effectScope().stop()` في الاختبارات والسكربتات العادية. لو استدعيت الـ
  composable خارج أي scope، ما عندها شي تتخلص منه، فاستدعِ `stop()`
  بنفسك.

تقدر تستورد الـ reducer والـ stream parser من نفس الـ subpath
(`reduceAgentEvents` و`initialAgentUIState` و`parseEventStream`)، وهي نفس
الموجودة في `@lousho/build-ai-agent/react`.

## Todos

`useTodos(agent)` تاخذ نتيجة الـ composable وترجّع ref واحد للقراءة فقط
لكل حقل في عرض الـ todos: `todos` و`counts` و`current` (عنصر الـ
`in_progress`، وإذا ما فيه، أول عنصر `pending`) و`progress`
(`completed / total`). تعرض خطة الـ agent اللي يستخدم
[todo tools](/ar/tools#todo-tools) live، من نفس الـ stream اللي يغذي
المحادثة (شوف [React](/ar/react#todos)).

```ts
import { useLoushoAgent, useTodos } from '@lousho/build-ai-agent/vue';

// In <script setup>:
const agent = useLoushoAgent({ url: '/api/agent' });
const { todos, counts, current, progress } = useTodos(agent);

export { agent, todos, counts, current, progress };
```

```html
<p>{{ counts.completed }} of {{ counts.total }} done ({{ Math.round(progress * 100) }}%)</p>
<p v-if="current">Now: {{ current.content }}</p>
<ul>
  <li v-for="todo in todos" :key="todo.id">{{ todo.status }}: {{ todo.content }}</li>
</ul>
```
