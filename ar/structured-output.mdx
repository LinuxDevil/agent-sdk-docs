مرّر للـ agent zod schema في الخيار `output`، والرد النهائي يصير object typed وصالح حسب الـ schema: `result.object`. الـ agent يقدر يعمل tool calls أولًا عادي؛ الإجابة النهائية فقط لازم تطابق الـ schema. بادئة `vendor/` في اسم الـ model هي التي تحدد الـ provider؛ ومع OpenRouter استخدم `openrouter/<vendor>/<model>` (مثال: `openrouter/openai/gpt-4o-mini`).

```ts
import { z } from 'zod';
import { createAgent } from '@lousho/build-ai-agent';

const agent = createAgent({
  model: 'openai/gpt-4o-mini',
  instructions: 'You report the weather.',
  output: z.object({ city: z.string(), tempC: z.number(), summary: z.string() }),
});

const result = await agent.send('Weather in Paris?');
if (result.object) {
  console.log(result.object.tempC); // typed: number
} else {
  console.error(result.finishReason, result.outputError?.issues); // 'output-invalid', [{ path, message }]
}
```

نوع `result.object` هو `z.output<typeof schema>`، فيطبّق zod عليه الـ defaults والـ transforms. أما `result.text` فيحتفظ بنص JSON الخام الذي كتبه الـ model.

الـ schema ممكن يكون zod 3 أو zod 4: يتحوّل إلى JSON Schema بـ`z.toJSONSchema` في zod 4 وبمحوّل `ai` SDK في zod 3، والـ validation في الحالتين يصير بـ`safeParse` الخاصة بالـ schema نفسه. نوع `output` هو Standard Schema، نفس `defineTool({ input })`، فيستنتج TypeScript نوع `result.object` بدون cast سواء كان الـ schema من zod 3، أو zod 4 (`zod/v4` على zod 3.25، أو zod 4 نفسه)، أو أي Standard Schema آخر يقدر ينتج JSON Schema:

```ts
import { z } from 'zod/v4';
import { createAgent } from '@lousho/build-ai-agent';

const agent = createAgent({ model: 'openai/gpt-4o-mini', output: z.object({ city: z.string() }) });
const { object } = await agent.send('Where is the Eiffel Tower?');
console.log(object?.city); // typed: string
```

## Sessions

`agent.session()` على agent له `output` يرجّع session نتيجة `send()` فيها (وكذلك `result` في `stream()`) تحمل الـ`object` typed لكل turn. ما فيه `output` مختلف لكل نداء: الـ schema هو schema الـ agent.

```ts
import { z } from 'zod';
import { createAgent } from '@lousho/build-ai-agent';

const agent = createAgent({ model: 'openai/gpt-4o-mini', output: z.object({ city: z.string(), tempC: z.number() }) });
const session = agent.session();
const { object } = await session.send('Weather in Paris?');
console.log(object?.tempC); // typed: number
```

## Sub-agents

الـ sub-agent الذي له `output` schema خاص يرد على الـ lead بالـ object بعد الـ validation. نتيجة الـ tool `task` (وكذلك `result` في `agent_await` لمهمة تعمل في الخلفية) هي الـ object كـ JSON، بعده سطر فارغ ثم الـ footer المعتاد `[sub-agent '<name>': ... taskId '<id>']`، فالـ lead model يقرأ الـ object نفسه بدل صياغة نثرية عنه. وإذا ظل رد الـ sub-agent غير صالح بعد خطوة الإصلاح، يفشل نداء `task` بخطأ tool منظم (`kind: 'execution'` ورسالة تذكر مشاكل الـ schema)، والـ lead يقدر يعمل retry أو يغيّر طريقته.

الـ sub-agent **لا** يرث `output` الخاص بالـ lead: مخرجات كل agent خاصة فيه، والـ sub-agent بدون `output` يرجّع نص كالمعتاد. وإذا كان الـ agent المنشور وراء [`remoteAgent()`](/ar/sub-agents#remote-sub-agents) له `output` schema، يرجّع الـ object البعيد بنفس الطريقة (JSON ثم الـ footer)، مقروء من `object` في حدث `run.done` في الـ stream البعيد.

```ts
import { z } from 'zod';
import { createAgent } from '@lousho/build-ai-agent';

const reporter = createAgent({
  model: 'openai/gpt-4o-mini',
  description: 'Reports the weather as { city, tempC }',
  output: z.object({ city: z.string(), tempC: z.number() }),
});
const lead = createAgent({ model: 'openai/gpt-4o-mini', subagents: { reporter } });
const result = await lead.send('What is the weather in Paris?');
console.log(result.text);
```

## كيف يشتغل

1. الـ system prompt يأخذ قسم `## Output format` يطلب الإجابة النهائية كـ JSON object فقط يطابق الـ schema، معروض كـ JSON Schema.
2. كل نداء للـ model يحمل `responseFormat: { type: 'json', schema }` في `GenerateOptions`. هو مجرد hint: الـ providers المدمجين المبنيين على `ai`-SDK يفعّلون JSON mode في الـ model (مع الـ schema في الـ models التي تدعم structured outputs)، والـ custom provider يقدر يستخدمه أو يتجاهله.
3. لما الـ model يرد بدون tool calls، يتحلّل الرد كـ JSON (ووجود code fence ```` ```json ```` حوله مسموح) ثم يصير validation عليه بالـ schema.
4. إذا كان غير صالح، الـ model يأخذ خطوة إصلاح واحدة: رسالة user تبدأ بـ`[output-invalid]` وتعدّد المشاكل، مثلا `1 issue (tempC: Expected number, received string)`. خطوة الإصلاح تنحسب من `maxSteps`، وما فيه خطوة إذا خلصت الميزانية.
5. وإذا ظل غير صالح، الـ run يعمل resolve (ليس reject) مع `finishReason: 'output-invalid'`، بدون `object`، ومع `outputError`: `{ message, issues: [{ path, message }] }`.

## Streaming

`agent.stream()` يشتغل بنفس الطريقة: `run.result` يعمل resolve ومعه `object`، والحدث الأخير `run.done` يحمل `object` (مرمّز كـ JSON) إذا كان الرد صالح. خطوة الإصلاح تظهر كزوج زيادة من `step.start` / `step.done`. شوف [Streaming](/ar/streaming).

## متقدم: executor API

`AgentExecutor.execute()` و`AgentExecutor.stream()` يأخذون نفس خيار `output`. هناك نوع `result.object` هو `unknown`؛ حلّله مرة ثانية بالـ schema، أو استخدم `createAgent()` إذا تريد النوع المستنتج.

```ts
import { z } from 'zod';
import { AgentBuilder, AgentExecutor } from '@lousho/build-ai-agent/executor';
import { createMockProvider } from '@lousho/build-ai-agent';

const Ticket = z.object({ title: z.string(), priority: z.enum(['low', 'high']) });
const agent = AgentBuilder.create().setName('triage').setPrompt('You triage bug reports.').build();
const result = await AgentExecutor.execute({ agent, input: 'The app crashes on login', provider: createMockProvider(), output: Ticket });
const ticket = result.object === undefined ? undefined : Ticket.parse(result.object);
```

## Testing

مع `mockModel`، جهّز مسبقًا نص JSON الذي سيكتبه الـ model:

```ts
import { z } from 'zod';
import { createAgent } from '@lousho/build-ai-agent';
import { mockModel } from '@lousho/build-ai-agent/testing';

const agent = createAgent({ provider: mockModel(['{"city":"Paris","tempC":21}']), output: z.object({ city: z.string(), tempC: z.number() }) });
const { object } = await agent.send('Weather in Paris?');
console.log(object?.city); // 'Paris'
```
