`createRouteHandler(agent, options?)` يشغّل agent من ملف route في أي framework يستقبل الـhandlers فيه `Request` ويرجّع `Response`: Next.js App Router، SvelteKit، Remix / React Router، Hono، Bun.serve. هو غلاف رفيع فوق نفس session API المستخدم في `lousho dev` وفي السيرفر المنشور ([النشر](/ar/deployment))، فالـbindings الخاصة بـReact وVue وSvelte تشتغل معه بدون أي تغيير. لا يستورد أي framework ولا أي module من `node:*`. بادئة `vendor/` على الـmodel هي التي تحدد الـprovider؛ ومع OpenRouter استخدم `openrouter/<vendor>/<model>` (مثل `openrouter/openai/gpt-4o-mini`).

## Next.js App Router

```ts
// app/api/agent/[[...path]]/route.ts
import { createAgent, createRouteHandler, memoryStore } from '@lousho/build-ai-agent';

// `store` is what lets a session survive across requests: without one every
// `agent.session({ id })` the handler opens gets a fresh in-memory transcript,
// so a second turn forgets the first and `GET /chat/:id` returns empty.
const agent = createAgent({
  model: 'openai/gpt-4o-mini',
  instructions: 'You are helpful.',
  store: memoryStore(), // lives in the server process; use a durable store on serverless
});

export const { GET, POST } = createRouteHandler(agent, {
  basePath: '/api/agent',
  auth: process.env.AGENT_TOKEN,
  uiMessageStream: true,
});
```

**route بدون `auth` يعني public**: أي حد يوصل له يقدر يشغّل الـagent تبعك ويصرف ميزانية الـmodel. مرّر bearer token، أو function تتحقق من الـsession أو الـcookie تبعتك:

```ts
import { createAgent, createRouteHandler } from '@lousho/build-ai-agent';

declare function isSignedIn(request: Request): Promise<boolean>;

export const { GET, POST } = createRouteHandler(createAgent({ model: 'openai/gpt-4o-mini' }), {
  auth: (request) => isSignedIn(request),
});
```

## المسارات

كل المسارات تحت `basePath` (الافتراضي `/api/agent`). الـ`/` في الآخر مقبولة، وأي طلب خارج الـbase path يرجع 404.

| المسار | شو بيعمل |
| --- | --- |
| `POST <basePath>` | `{ input, sessionId? }`: الـturn يوصل streaming عبر SSE. هذا اللي يرسله `useLoushoAgent({ url })`؛ بدون `sessionId` كل turn يفتح session جديدة |
| `POST <basePath>/approvals/:id` | `{ approved, note? }` أو `{ answer }`: الاستكمال يوصل streaming (نفس `approvalsUrl` في `useLoushoAgent`) |
| `POST <basePath>/chat` | `{ sessionId, input }`: نفس session API تبع السيرفر المنشور |
| `GET <basePath>/chat/:sessionId` | الـtranscript تبع الـsession والـapprovals (موافقات) المعلّقة |
| `POST <basePath>/chat/:sessionId/approvals/:id` | تحسم approval داخل session |
| `POST <basePath>/ui` | مع `uiMessageStream: true`: الـendpoint الذي يستخدمه `useChat` من AI SDK |
| `GET <basePath>/oauth/callback` | الـredirect من الـOAuth provider بعد تسجيل الدخول؛ لا يمر على `auth` أبدًا (يحميه `state` اللي ينستخدم مرة وحدة) |
| `GET <basePath>/health` | `ok`، ولا يمر على `auth` أبدًا |

الـagent يحتفظ بالـsessions عبر `store` (`createAgent({ store })`). إذا بتستخدم sessions على serverless، أعطِ الـagent ‏`store` يعيش أطول من استدعاء واحد.

`auth` يقبل أيضًا قائمة مرتبة من `jwt()` و`oidc()` و`basic()` و`apiToken()`. المتصل اللي بتقبله القائمة يوصل للـrun باسم `principal`. التفاصيل في [auth المسارات والـprincipals](/ar/auth).

## Client: `useLoushoAgent`

```tsx
'use client';
import { useLoushoAgent } from '@lousho/build-ai-agent/react';

export function Chat() {
  const agent = useLoushoAgent({ url: '/api/agent', headers: { Authorization: `Bearer ${token}` } }, { approvalsUrl: '/api/agent/approvals' });
  // agent.messages, agent.send(text), agent.approve() ...
}
```

## Client: `useChat`

مع `uiMessageStream: true`، وجّه `useChat` على الـroute تبع `ui`. الـ`id` تبع الشات هو اسم الـsession، فاللي يوصل للـagent هو آخر رسالة من المستخدم فقط ([AI SDK UI](/ar/ai-sdk-ui)).

```tsx
import { useChat } from '@ai-sdk/react';
import { DefaultChatTransport } from 'ai';

// ai 6/7 signature; on ai 4 (also a supported peer) use useChat({ api: '/api/agent/ui' })
const { messages, sendMessage } = useChat({ transport: new DefaultChatTransport({ api: '/api/agent/ui' }) });
```

## Frameworks أخرى

نفس الـhandler، ركّبه بالمكان اللي الـframework يتوقعه:

```ts
import { createAgent, createRouteHandler } from '@lousho/build-ai-agent';

const { handler } = createRouteHandler(createAgent({ model: 'openai/gpt-4o-mini' }), { basePath: '/agent', auth: 'secret' });

// SvelteKit: src/routes/agent/[...path]/+server.ts
export const GET = ({ request }: { request: Request }) => handler(request);
export const POST = ({ request }: { request: Request }) => handler(request);

// Hono: app.all('/agent/*', (c) => handler(c.req.raw))
// Bun.serve: fetch: handler
```
