## النماذج وجدول الأسعار

دوال مساعدة بلا اعتماديات لقرارات الميزانية والسياق.

```ts
import { estimateTokens, estimateCost, getModelInfo, registerModel } from '@lousho/build-ai-agent';

// A custom or self-hosted model: add it (or override a built-in) before use.
registerModel({
  id: 'my-llama',
  provider: 'ollama',
  contextWindow: 32768,
  inputCostPerMTok: 0.2, // optional; omit for unknown or free
  outputCostPerMTok: 0.6,
});

const used = estimateTokens([{ role: 'user', content: 'Summarise this report' }], { model: 'my-llama' });
const info = getModelInfo('openai/gpt-4o-mini'); // exact id, `provider/id`, or a dated snapshot
const usd = estimateCost({ inputTokens: used, outputTokens: 500 }, 'my-llama'); // undefined if unpriced
```

- `estimateTokens(input, { model?, estimator? })` تقدير تقريبي (نحو 4 محارف لكل رمز في الإنجليزية، وأكثر في الصينية واليابانية والكورية وغيرها من أنظمة الكتابة، إضافةً إلى كلفة إضافية لكل رسالة وJSON استدعاءات الأدوات). توقّع خطأً يقارب 15-20% في الإنجليزية: يكفي لضغط السياق والميزانيات، ولا يصلح للفوترة. ويمكنك توصيل مُرمِّز (tokenizer) حقيقي بـ`setTokenEstimator(fn)` أو بـ`options.estimator`.
- `getModelInfo(id)` يطابق المعرّف كما هو أولًا، ثم `provider/id`، ثم اللقطات المؤرَّخة (`gpt-4o-mini-2024-07-18` تُحلّ إلى `gpt-4o-mini`). والنماذج غير المعروفة تُرجع `undefined`.
- `registerModel(info)` يضيف مدخلًا أو يتغلّب على مدخل موجود؛ والتسجيل الأحدث هو الذي يسري.
- `estimateCost(usage, model)` يُرجع التكلفة بالدولار الأمريكي، أو `undefined` (لا `0`) حين يكون النموذج أو أسعاره غير معروفة.

نوافذ السياق والأسعار المضمَّنة لقطة مؤرَّخة (انظر تاريخ الجلب والمصادر في أعلى `src/models/modelData.ts`). تغيّر المزوّدون أسعارهم ونماذجهم، فتغلّب على المدخلات بـ`registerModel` حين تحتاج إلى أرقام بمستوى الفوترة.

## استهلاك التشغيل وتكلفته

تحمل كل `ExecutionResult` (ونتيجة `agent.send()`) الحقل `usage`، وهو المجموع الجاري للتشغيل كله:

```ts
import { createAgent, formatUsage } from '@lousho/build-ai-agent';

const result = await createAgent({ provider, instructions: 'You compare cities.' }).send('Compare 3 cities');

result.usage.inputTokens; // all model calls of the run, delegated children included
result.usage.costUsd; // number, or undefined if any model used has no known price
result.usage.estimated; // true if some call reported no usage and was estimated
result.usage.byModel['gpt-4o-mini']; // { inputTokens, outputTokens, costUsd?, calls }
result.stepUsage?.[0]; // { step, model, usage, estimated, costUsd? } per model call
console.log(formatUsage(result.usage)); // 1,234 in / 567 out tokens · $0.0042 (2 model calls)
```

- **المُبلَّغ عنه مقابل المقدَّر.** يبلّغ المزوّدون عن `promptTokens`/`completionTokens`؛ وتمرّر المزوّدات المضمَّنة أيضًا `cachedInputTokens`/`reasoningTokens` حين تحملها البيانات الوصفية لمزوّد حزمة 'ai' SDK (ولا يظهر `usage.cachedInputTokens` و`usage.reasoningTokens` إلا حينئذ). والواجهة الخلفية التي لا تبلّغ عن شيء تعطي استهلاكًا `undefined`، لا أصفارًا أبدًا. وفي تلك الخطوة يعود المنفِّذ إلى `estimateTokens` ويعيّن `usage.estimated` (تظهر `~` في بداية الناتج من `formatUsage`). والمزوّد المخصَّص ينبغي أن يترك `GenerateResult.usage` غير معيّن بدل أن يملأه بأصفار.
- **التكلفة.** `costUsd` هو مجموع `estimateCost` لكل نموذج. وهو `undefined`، ولا يكون أبدًا مجموعًا جزئيًا مضلِّلًا، بمجرد أن يكون سعر أي نموذج مستخدَم غير معروف؛ ويبيّن `byModel` أيَّها له سعر.
- **التفويض.** يُضاف استهلاك الابن المفوَّض إلى مجاميع الأب و`byModel`، ويظهر أيضًا منفردًا في `usage.delegated` (`{ inputTokens, outputTokens, totalTokens, costUsd, modelCalls, estimated, runs }`). أما استهلاك [الوكيل الفرعي البعيد](/ar/sub-agents#الوكلاء-الفرعيون-عن-بُعد) فهو ما يبلّغ عنه الوكيل البعيد، ويُسجَّل تحت `byModel['remote:<name>']` مع `costUsd` الخاصة بالوكيل البعيد.
- **الاستئناف.** التشغيل المستأنَف من نقطة حفظ، أو بعد موافقة، يتابع من المجاميع المحفوظة بدل أن يبدأ من الصفر. ونقاط الحفظ التي كتبتها إصدارات أقدم تبدأ من أعداد الرموز المحفوظة فيها وبتكلفة غير معروفة.
- **الأحداث والتتبّع.** يحمل الحدث `finish` (وكل حدث دورة حياة كان يحمل `usage`) الآن المجاميع الجارية؛ ويحمل `text-complete` أيضًا `stepUsage`، ويتلقى `onLLMResponse` استهلاك الاستدعاء وسيطًا ثالثًا. وتستخدم سمات `gen_ai.usage.*` في المقطع (span) `chat` الأرقام نفسها، مع تعيين `lousho.usage.estimated` إلى `true` حين تكون تقديرات.
- **البث.** تحمل أحداث `agent.stream()` المحاسبة نفسها: في `step.done` و`run.done` الحقل `usage` ويضم `inputTokens` و`outputTokens` و`estimated` و`costUsd` (وعلى مستوى التشغيل أيضًا `modelCalls`)، إلى جانب `promptTokens`/`completionTokens` الأقدم.
- يبقى `promptTokens` و`completionTokens` في `usage` اسمين بديلين مُهمَلين لـ`inputTokens` و`outputTokens`.

تأتي الأسعار من سجل النماذج أعلاه، فللحصول على تكلفة نموذج مخصَّص أو مضبوط بدقة (fine-tuned) سجّله بالمعرّف الذي تمرّره بوصفه النموذج:

```ts
import { registerModel } from '@lousho/build-ai-agent';

registerModel({
  id: 'ft:gpt-4o-mini:acme',
  provider: 'openai',
  contextWindow: 128000,
  inputCostPerMTok: 0.3,
  outputCostPerMTok: 1.2,
});
```
