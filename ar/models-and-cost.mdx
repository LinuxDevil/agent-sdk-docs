## الـ models وجدول الأسعار


دوال مساعدة بدون dependencies، لقرارات الميزانية والسياق.

```ts
import { estimateTokens, estimateCost, getModelInfo, registerModel } from '@lousho/build-ai-agent';

// A custom or self-hosted model: add it (or override a built-in) before use.
registerModel({
  id: 'my-llama',
  provider: 'ollama',
  contextWindow: 32768,
  inputCostPerMTok: 0.2, // optional; omit for unknown or free
  outputCostPerMTok: 0.6,
});

const used = estimateTokens([{ role: 'user', content: 'Summarise this report' }], { model: 'my-llama' });
const info = getModelInfo('openai/gpt-4o-mini'); // exact id, `provider/id`, or a dated snapshot
const usd = estimateCost({ inputTokens: used, outputTokens: 500 }, 'my-llama'); // undefined if unpriced
```

- `estimateTokens(input, { model?, estimator? })` هو heuristic تقريبي: حوالي 4 محارف لكل token في الإنجليزية، وأكثر للـ CJK وباقي أنظمة الكتابة، زائد overhead لكل رسالة ولـ JSON الخاص بالـ tool calls. توقّع خطأ بحوالي 15-20% في الإنجليزية — يكفي للـ compaction (ضغط السياق) والميزانيات، لكنه لا يصلح للفوترة. وصّل tokenizer حقيقي عبر `setTokenEstimator(fn)` أو `options.estimator`.
- `getModelInfo(id)` يطابق الـ id كما هو أولًا، ثم `provider/id`، ثم الـ snapshots المؤرخة (`gpt-4o-mini-2024-07-18` ترجع `gpt-4o-mini`). الـ models غير المعروفة ترجع `undefined`. (في سلاسل `createAgent({ model })` و`resolveProvider()`، بادئة `vendor/` هي التي تختار الـ provider؛ ومع OpenRouter استخدم `openrouter/<vendor>/<model>`، مثل `openrouter/openai/gpt-4o-mini`.)
- `registerModel(info)` يضيف مدخلًا جديدًا أو يكتب فوق مدخل موجود، وآخر تسجيل هو الذي يُعتمد.
- `estimateCost(usage, model)` يرجع التكلفة بالدولار (USD)، أو `undefined` (وليس `0`) إذا كان الـ model أو أسعاره غير معروفة.

الـ context windows والأسعار المضمّنة snapshot مؤرخة (تاريخ الجلب والمصادر في أعلى `src/models/modelData.ts`). الـ providers يغيّرون أسعارهم والـ models، فإذا تحتاج أرقامًا بدقة الفوترة اكتب فوق المدخلات بـ`registerModel`.

## الـ usage وتكلفة الـ run

كل `ExecutionResult` (ونتيجة `agent.send()`) تحمل `usage`، وهو المجموع التراكمي للـ run كله:

```ts
import { createAgent, formatUsage } from '@lousho/build-ai-agent';

const result = await createAgent({ provider, instructions: 'You compare cities.' }).send('Compare 3 cities');

result.usage.inputTokens; // all model calls of the run, delegated children included
result.usage.costUsd; // number, or undefined if any model used has no known price
result.usage.estimated; // true if some call reported no usage and was estimated
result.usage.byModel['gpt-4o-mini']; // { inputTokens, outputTokens, costUsd?, calls }
result.stepUsage?.[0]; // { step, model, usage, estimated, costUsd? } per model call
console.log(formatUsage(result.usage)); // 1,234 in / 567 out tokens · $0.0042 (2 model calls)
```

- **reported مقابل estimated.** الـ providers يبلّغون عن `promptTokens`/`completionTokens`. والـ providers المضمّنون يمرّرون أيضًا `cachedInputTokens`/`reasoningTokens` إذا حملتها الـ metadata الخاصة بالـ provider في حزمة 'ai' SDK — `usage.cachedInputTokens` و`usage.reasoningTokens` لا يظهران إلا في تلك الحالة. الـ backend الذي لا يبلّغ عن شيء يعطي `usage` بقيمة `undefined`، لا أصفارًا أبدًا. في تلك الخطوة يستعمل الـ executor الدالة `estimateTokens` كـ fallback ويضبط `usage.estimated` (تظهر `~` في بداية ناتج `formatUsage`). والـ provider المخصص يجب أن يترك `GenerateResult.usage` غير مضبوط بدل أن يملأه بأصفار.
- **التكلفة.** `costUsd` هو مجموع `estimateCost` لكل model. يصير `undefined` — لا مجموعًا جزئيًا مضللًا — بمجرد أن يكون أي model مستخدم بلا سعر معروف، و`byModel` يوضح أيها مسعَّر. `formatUsage` يطبع التكلفة بأربع خانات عشرية تحت $1 (وخانتين عند $1 فأكثر)، فالـ run الذي يقل عن $0.00005 يظهر `$0.0000`.
- **hosted tools.** `usage.hostedToolCalls` يحسب الاستدعاءات التي شغّلها الـ provider للـ [hosted tools](/ar/hosted-tools) لكل اسم tool (مثل `{ web_search: 2 }`). رسوم الاستدعاء يحاسب عليها الـ provider نفسه وهي ليست ضمن `costUsd`.
- **التفويض.** يُضاف الـ usage الخاص بالـ child المفوَّض إلى مجاميع الأب و`byModel`، ويظهر أيضًا منفردًا في `usage.delegated` (`{ inputTokens, outputTokens, totalTokens, costUsd, modelCalls, estimated, runs }`). أما الـ usage الخاص بالـ[remote sub-agent](/ar/sub-agents#remote-sub-agents) فهو ما يبلّغ عنه الـ agent البعيد، ويُسجَّل تحت `byModel['remote:<name>']` مع `costUsd` الخاصة به.
- **الاستئناف.** الـ run الذي يُستأنف من checkpoint أو بعد موافقة يكمل من المجاميع المحفوظة بدل أن يبدأ من الصفر. الـ checkpoints التي كتبتها إصدارات أقدم تبدأ من أعداد الـ tokens المحفوظة فيها وبتكلفة غير معروفة.
- **الأحداث والـ tracing.** الحدث `finish` (وكل lifecycle event كان يحمل `usage`) يحمل الآن المجاميع التراكمية. و`text-complete` يحمل أيضًا `stepUsage`، و`onLLMResponse` يستقبل الـ usage الخاص بالاستدعاء كوسيط ثالث. سمات `gen_ai.usage.*` في الـ span `chat` تستخدم نفس الأرقام، مع `lousho.usage.estimated` مضبوطة على `true` إذا كانت الأرقام تقديرية.
- **streaming.** أحداث `agent.stream()` تحمل نفس المحاسبة: `step.done` و`run.done` فيها `usage` يضم `inputTokens` و`outputTokens` و`estimated` و`costUsd` (وعلى مستوى الـ run أيضًا `modelCalls`)، إلى جانب `promptTokens`/`completionTokens` الأقدم.
- يبقى `promptTokens` و`completionTokens` على `usage` اسمين بديلين deprecated لـ`inputTokens` و`outputTokens`.

الأسعار تأتي من الـ model registry أعلاه، فإذا أردت تكلفة لـ model مخصص أو fine-tuned، سجّله بنفس الـ id الذي تمرّره كـ model:

```ts
import { registerModel } from '@lousho/build-ai-agent';

registerModel({
  id: 'ft:gpt-4o-mini:acme',
  provider: 'openai',
  contextWindow: 128000,
  inputCostPerMTok: 0.3,
  outputCostPerMTok: 1.2,
});
```
