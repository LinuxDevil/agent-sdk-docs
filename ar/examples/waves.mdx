**Waves** (Workers · Aggregate · Verify · Extend، أي العمّال والتجميع والتحقق والتوسيع) هو نمط التوازي المحدود المأخوذ من مسارات عمل "waves" المجتمعية (rayfernando-skills وWave-Engineering/claudecode-workflow). على خلاف التوزيع البسيط للمهام (fan-out)، تملك الموجة *عمودًا فقريًا للتحقق*: تُدمَج مخرجات العمّال بطريقة حتمية، ثم يحكم مُتحقِّق (verifier) على الناتج المجمَّع وفق مخطط مُنمَّط، ولا تعمل موجة لاحقة **إلا** على الثغرات التي يسمّيها المُتحقِّق.

```text
         ┌────────────────────────── wave ──────────────────────────┐
tasks ──►│  worker(worker-1)   worker(worker-2)   worker(worker-3)  │──► outputs
         │          (bounded parallel, concurrency-sized chunks)    │
         └──────────────────────────────────────────────────────────┘
                              │ aggregate (deterministic merge)
                              ▼
                        verifier: { verdict, gaps[] }
                          │              │
                     'pass' │              │ 'extend'
                          ▼              ▼
                        result    gaps → tasks → next wave
```

## المقابلة بين الخطوات وواجهات Lousho

| خطوة الموجة | واجهة Lousho المقابلة |
| ---------- | -------------- |
| العمّال    | `Promise.all` على `agent.send()`، فالـ harness يملك شكل الموجة، وكل عامل هو `createAgent` جديد كي تبقى السياقات نظيفة |
| التجميع  | دالة عادية حتمية، فإسقاط مساهمة ما يُعدّ خطأً برمجيًا لا دمجًا صامتًا |
| التحقق     | `createAgent({ output: VERDICT })`، وهو قرار مُنمَّط: `{ verdict: 'pass'\|'extend', gaps: string[] }` |
| التوسيع     | `verdict.gaps.map(gapToTask)` يملأ قائمة مهام الموجة التالية |

لتشغيله:

```bash
npm run example:waves            # offline, scripted workers + verifier
OPENROUTER_API_KEY=… npx tsx examples/waves/index.ts   # live
```

متى تلجأ إليه: في العمل الذي يتّسع عرضًا أولًا ويمكن فيه التحقق من *التغطية*، مثل تلخيص مجموعة نصوص أو تدقيق قاعدة كود أو ترحيل ملفات، وحين تكون الإجابة الجزئية أسوأ من الإجابة البطيئة. وحين يستطيع منسّق واحد أن يستوعب المهمة كلها، يكون شكل [deep-research](https://github.com/LinuxDevil/lousho/blob/main/examples/deep-research/)، الذي يوزّع فيه الـ agent الرئيسي المهام الفرعية، أبسط.
