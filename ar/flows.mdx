مسار العمل هو سير عمل ثابت متعدد الخطوات ينفّذه وكيل واحد: تُكتب الخطوات وترتيبها مسبقًا بدل تركها لتقدير النموذج. صِف الرسم البياني (graph) بـ`FlowBuilder` ونفّذه بالدالة الساكنة `FlowExecutor.execute(flow, context, onEvent?)`.

```ts
import { FlowBuilder, FlowExecutor, type EditorStep } from '@lousho/build-ai-agent/flows';

// FlowBuilder is a metadata builder: setCode/setName/setInputs/setFlow(...).build().
// EditorStep covers every node type FlowExecutor runs ('sequence', 'llmCall',
// 'oneOf', 'setVariable', ...).
const steps: EditorStep = {
  type: 'sequence',
  steps: [
    { type: 'llmCall', prompt: 'Classify this message as billing, technical or sales: {{message}}', outputVariable: 'category' },
    { type: 'llmCall', prompt: 'Write a one-line reply for a {{category}} request: {{message}}' },
  ],
};

const flow = new FlowBuilder()
  .setCode('triage')
  .setName('Triage')
  .addInput({ name: 'message', type: 'shortText', required: true })
  .setFlow(steps)
  .build();

// FlowExecutor is a static API too: execute(flow, context, onEvent?)
const result = await FlowExecutor.execute(flow, { agent, provider, variables: { message: input } });
```

## أنواع العُقد

ينفّذ `FlowExecutor` أنواع العُقد التالية:

| `type` | ما يفعله |
| ------ | ------------ |
| `sequence` | ينفّذ خطواته `steps` واحدة تلو الأخرى. |
| `parallel` | ينفّذ خطواته في الوقت نفسه. |
| `llmCall` | يستدعي النموذج بموجّه `prompt` (فيه عناصر نائبة بصيغة `{{variable}}`)؛ ويخزّن `outputVariable` الرد. |
| `toolCall` | يستدعي أداة بالمعاملات `arguments` (مع تعويض العناصر النائبة). |
| `setVariable` | يضبط `variable` على القيمة `value`. |
| `oneOf` | يسلك أول فرع يتحقق شرطه. |
| `forEach` | ينفّذ خطوة لكل عنصر من `items`، واحدًا تلو الآخر. |
| `evaluator` | يقيّم تعبيرًا على متغيرات مسار العمل. |
| `return`، `end` | يُنتجان `value` الخاصة بالعقدة نتيجةً. |
| `throw` | يُفشِل مسار العمل بـ`message` الخاصة بالعقدة (تُدرج فيها العناصر النائبة `{{variable}}`؛ الافتراضي `'Flow error'`). |

شروط `oneOf` وتعبيرات `evaluator` تستخدم لغة تعبيرات صغيرة وآمنة (لا `eval`، ولا شيفرة من المضيف؛ والعناصر النائبة `{{name}}` تُربط قيمًا، ولا تُلصق في التعبير أبدًا). قواعدها النحوية وقواعد فشلها في [تعبيرات مسارات العمل](#تعبيرات-مسارات-العمل).

## مسارات عمل أم وكلاء فرعيون أم مهارات؟

استخدم مسار عمل حين يكون خط المعالجة معروفًا مسبقًا؛ واستخدم [الوكلاء الفرعيين](/ar/sub-agents) حين ينبغي أن يقرر النموذج ما يفوّضه، و[المهارات](/ar/skills) حين يحتاج الوكيل نفسه إلى تعليمات إضافية لبعض المهام فحسب. راجع [وكلاء فرعيون أم مهارات أم مسارات عمل؟](/ar/sub-agents#وكلاء-فرعيون-أم-مهارات-أم-مسارات-عمل؟).

تُتتبَّع مسارات العمل مثل تشغيلات الوكيل (راجع [التتبّع والمراقبة](/ar/observability#مسارات-العمل)).

## تعبيرات مسارات العمل

تُقيَّم شروط الفروع في `oneOf` (وشروط فروع عقدة الموجِّه router في Agent Forge) وتعبيرات العقدة `evaluator` بمقيِّم تعبيرات صغير مدمج. هو لا يُصرِّف شيفرة المضيف ولا ينفّذها: لا يوجد `eval` ولا `new Function` ولا `vm` في `src/flows`. والعناصر النائبة `{{name}}` تُربط قيمًا ولا تُلصق في نص التعبير: فـ`{{score}} >= 90` المجرّدة تستخدم قيمة المتغير، وداخل سلسلة نصية حرفية، فإن `'{{classify}}' === 'refund'` تدرج نص القيمة في تلك السلسلة بعد أن يكون التعبير قد جُزِّئ إلى وحداته (tokenized). ولذلك فالمتغير الذي تحتوي قيمته على علامات اقتباس أو شرطات مائلة عكسية أو معاملات (مثل `x' === 'x' || 'a`) ليس سوى بيانات ولا يستطيع تغيير منطق الشرط. والمتغير المفقود أو `null` يكون سلسلة فارغة داخل السلسلة الحرفية؛ وإن استُخدم مجرّدًا فلا يساهم بشيء، فتكون `{{missing}} >= 90` خطأً نحويًا ويُعدّ الشرط غير متحقق. ويُقيَّم التعبير على متغيرات مسار العمل.

| الصيغة | أمثلة |
| --- | --- |
| القيم الحرفية | `'text'`, `"text"`, `42`, `1.5`, `true`, `false`, `null` |
| المتغيرات والمسارات | `score`, `user.address.city`, `user['first-name']`, `items[0].id` |
| الطول | `name.length`, `items.length` (للسلاسل النصية والمصفوفات) |
| المقارنة | `==`, `===`, `!=`, `!==`, `<`, `<=`, `>`, `>=` |
| المنطقية | `&&`, `\|\|`, `!` (بالتقييم المختصر، وتُرجع المُعامِل الحاسم) |
| الحسابية | `+`, `-`, `*`, `/`, `%`, و`-` و`+` الأحاديتان |
| التجميع | `( ... )` |
| الدوال المسموح بها | `s.includes(x)` و`s.startsWith(x)` و`s.endsWith(x)` على السلاسل النصية؛ و`list.includes(x)` على المصفوفات (معامل واحد بالضبط) |

الأسبقية، من الأضعف إلى الأقوى: `||`، ثم `&&`، ثم المساواة، ثم العلاقات، ثم `+ -`، ثم `* / %`، ثم الأحادية، ثم الوصول إلى الأعضاء.

غير المدعوم يُرفض بـ`ExpressionError` يسمّي التعبير وموضع المحرف وقائمة الصيغ المدعومة هذه: أي استدعاء دالة أو طريقة آخر، والإسناد (`=` و`+=` و`++`)، والتعبير الشرطي الثلاثي، والسلاسل القالبية (template strings)، والقيم الحرفية للكائنات والمصفوفات، والوصول إلى `constructor` أو `__proto__` أو `prototype`، والمتغيرات العامة (`process` و`require` و`globalThis`، ...). لا يمكن الوصول إلا إلى متغيرات مسار العمل نفسه، وإلى خصائصها الخاصة بها فقط.

سلوك الفشل لم يتغير: شرط `oneOf` الذي يتعذر تقييمه يُعدّ غير متحقق (`false`)، وتعبير `evaluator` الذي يتعذر تقييمه يُفشل مسار العمل برسالة `Failed to evaluate expression: ...` مع تفاصيل `ExpressionError`.
