## What it deploys

`vps-ops` answers operator questions about the host it runs on: `host_status`
(OS, uptime, load, memory) is live facts, and a small scratchpad
(`write_note`/`read_note`/`list_notes`) persists operator notes — writes ask
for approval, reads are always allowed. The model is
`openrouter/openai/gpt-4o-mini`.

## Run it

```bash
npx lousho deploy --host <server-ip> --agent examples/hostinger-deploy/agent --no-studio
```

The wizard asks for the model key (`OPENROUTER_API_KEY`) and generates the
`LOUSHO_API_TOKEN` bearer. Then:

```bash
curl -N https://agent.<server-ip-with-dashes>.sslip.io/chat \
  -H "Authorization: Bearer $LOUSHO_API_TOKEN" -H 'Content-Type: application/json' \
  -d '{"sessionId": "me", "input": "What is the load?"}'
```

See [Deploying to your own server](https://github.com/LinuxDevil/lousho/blob/main/docs/hostinger-vps.md).
